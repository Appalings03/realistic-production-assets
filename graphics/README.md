This folder contains graphics used by the realistic_production_assets mod.

Place icon files here for prototypes defined in other submods.

Conventions:

- Each prototype should get its own folder, e.g.:
  realistic-iron-ore/icon.png
  realistic-copper-ore/icon.png
- Icon format: PNG, recommended size 32x32, transparent background.
- If you want 64x64 or atlas sprites, update prototypes/util.lua accordingly.
